## О приложении

Ser-Net для Android — мобильный VPN-клиент поверх [Xray-core](https://github.com/XTLS/Xray-core). Он берёт серверы из обычной ссылки подписки вашего провайдера, поднимает туннель через системный `VpnService` и позволяет выбрать, куда идти трафику: пускать Россию напрямую, вести всё через VPN или завернуть только выбранные приложения.

Это та же идея, что и в [версии для Windows](https://github.com/bgkv44/Ser-Net), но реализованная отдельно под Android: туннель держит `VpnService`, ядро Xray работает из Kotlin через LibXray, а интерфейс управляется из шторки, уведомления и плитки быстрых настроек.

> [!NOTE]
> Ser-Net не предоставляет VPN-серверы, подписки и доступ к инфраструктуре. Для работы нужна собственная совместимая ссылка или подписка от вашего провайдера.

## Возможности

| Возможность | Описание |
|---|---|
| **Подписки** | Несколько ссылок одновременно, карточки с остатком трафика и сроком, обновление отдельной подписки без переключения остальных. |
| **Выбор сервера** | Поиск по названию и стране, задержка у каждого узла, отметка «не проверен» вместо выдуманных цифр. |
| **Замер задержки** | Пять способов: `Ser-Net` (реальный HTTP-запрос через сервер), `GET`/`HEAD` через сервер, `TCP`, `ICMP`. Способ и таймаут выбираются в настройках. |
| **TUN-туннель** | Собственный `VpnService`: виртуальный интерфейс идёт на всё устройство, сокеты ядра защищены `protect()`. |
| **Выбор приложений** | Туннель только для выбранных приложений или для всех, кроме исключённых. |
| **Маршрутизация** | «Умный режим», «Весь трафик через VPN» и «Только выбранное» с готовыми наборами правил и своими доменами. |
| **Плитка в шторке** | Подключение и отключение одним касанием, состояние и имя сервера прямо на плитке. |
| **Уведомление** | Статус туннеля, скорость и кнопки «Пауза», «Старт» и «Отмена» без открытия приложения. |
| **Обход DPI** | Фрагментация TLS для профилей TLS/REALITY, если соединение режут по SNI. |
| **Блокировка рекламы** | Фильтр рекламных доменов на уровне ядра. |
| **Защита при запуске** | При старте приложение проверяет серверы и подключается к самому быстрому. |
| **Ввод подписки** | Вставка ссылки из буфера обмена или сканирование QR-кода камерой. |
| **Оформление** | Светлая, тёмная или системная тема; интерфейс подстраивается под вырезы и клавиатуру. |
| **Диагностика** | Версия ядра, версия службы, HWID и модель устройства в разделе «О приложении». |

## Поддерживаемые транспорты

TCP · WebSocket (WS) · gRPC · XHTTP · HTTP

Доступность конкретного транспорта зависит от серверной конфигурации и совместимости с Xray-core. Правила `geoip:`/`geosite:` работают: файлы geodata поставляются вместе с приложением и распаковываются во внутреннюю папку при первом запуске.

## Как работает туннель

1. Вы нажимаете кнопку подключения — приложение просит разрешение VPN (один раз).
2. `VpnService` создаёт интерфейс `tun0` и передаёт его дескриптор ядру Xray.
3. Ядро поднимает прокси-соединение с выбранным сервером; все его сокеты проходят через `VpnService.protect()`, поэтому трафик не зацикливается.
4. DNS внутри туннеля обслуживает Go-резолвер, привязанный к защищённому сокету.
5. При отключении служба останавливает ядро и закрывает интерфейс — приложение продолжает работать, настройки и сервер сохраняются.

Туннель на Android один — TUN. Отдельного режима «системный прокси», как в Windows, здесь нет: мобильной системе нужен именно виртуальный интерфейс.

## Требования

- Android 7.0 (API 24) или новее. Собрано и проверено на Android 14.
- Процессор с поддержкой `arm64-v8a` (почти все устройства), `armeabi-v7a` (старые 32-битные), `x86`/`x86_64` (эмуляторы).
- Собственная ссылка подключения или подписка.
- Разрешение VPN, которое Android запросит при первом подключении.

## Установка

1. Откройте [страницу релизов](https://github.com/bgkv44/Ser-Net-android/releases).
2. Скачайте APK под свой процессор:

| Файл | ABI | Кому |
|---|---|---|
| `Ser-Net_1.0.0-beta.1.7_arm64-v8a.apk` | `arm64-v8a` | почти все телефоны и планшеты с 2017 года |
| `Ser-Net_1.0.0-beta.1.7_armeabi-v7a.apk` | `armeabi-v7a` | старые 32-битные устройства |
| `Ser-Net_1.0.0-beta.1.7_x86.apk` | `x86` | 32-битные эмуляторы |
| `Ser-Net_1.0.0-beta.1.7_x86_64.apk` | `x86_64` | эмуляторы и x86-планшеты |

   Не знаете свой ABI — берите `arm64-v8a`.
3. Разрешите установку из этого источника, если Android попросит.
4. Откройте файл и установите приложение.

Текущие сборки помечены как **бета** — это тестовые версии, которые могут меняться между релизами. APK подписаны одним ключом, поэтому новая версия ставится поверх старой без удаления данных.

## Первое подключение

1. Откройте раздел **«Подписки»** в нижней навигации и нажмите **«Добавить подписку»**.
2. Вставьте ссылку из буфера обмена или отсканируйте QR-код, затем нажмите **«Загрузить»**.
3. При нескольких подписках выберите активную — её серверы появятся на главном экране.
4. На экране **«Подключение»** выберите сервер и нажмите круглую кнопку питания.
5. Разрешите VPN в системном диалоге и, если нужно, отключите оптимизацию батареи для Ser-Net: некоторые прошивки закрывают фон, когда экран погашен.

## Плитка и уведомление

- **Плитка «Ser-Net»** в шторке быстрых настроек подключает и отключает VPN одним касанием и показывает выбранный сервер. Долгое нажатие открывает само приложение, а не системные «Сведения о приложении».
- **Уведомление** держит туннель в foreground-режиме и позволяет поставить соединение на паузу, продолжить или отменить его, не открывая приложение. На Android 13+ для него нужно разрешение на уведомления.

## Маршрутизация

| Режим | Поведение |
|---|---|
| **Умный режим** | Сайты России и локальная сеть идут напрямую, остальное — через VPN. Подходит для повседневной работы. |
| **Весь трафик через VPN** | Весь трафик идёт в туннель, кроме локальных сетей и заданных исключений. |
| **Только выбранное** | Через VPN идут только правила из списка «Через VPN», остальное — напрямую. |

Правила задаются наборами для сервисов, своими доменами и списком приложений: можно пустить в туннель только избранные приложения или исключить их из туннеля. При активном подключении изменения применяются кнопкой **«Применить»**.

## Обновление

Встроенного автообновления на Android нет: скачайте APK новой версии на [странице релизов](https://github.com/bgkv44/Ser-Net-android/releases) и установите поверх текущей. Подписки, сервер и настройки сохраняются, данные приложения не удаляются.

## Если что-то не работает

- **Серверы не появились** — проверьте ссылку подписки и нажмите «Обновить». При ошибке загрузки прежний список сохраняется.
- **Не подключается** — попробуйте другой сервер и другой способ замера задержки; убедитесь, что разрешение VPN выдано.
- **Туннель «падает» сам** — отключите для Ser-Net оптимизацию батареи и автозапуск ограничений прошивки (MIUI, ColorOS, OneUI) для фоновой работы.
- **Сайт идёт не тем маршрутом** — проверьте режим маршрутизации, набор правил и список приложений, затем нажмите «Применить».
- **Нужны детали** — откройте «Настройки» → «О приложении», запишите версию приложения, ядра и службы.
